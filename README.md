# Adarsh Dileep --- Developer Portfolio

> **I build. I debug. I engineer.**

A personal portfolio presenting my journey as a mobile-first software
engineer, with React Native as my primary specialization and additional
experience in React.js, PHP, and CodeIgniter.

This project is also a showcase of an AI-assisted design and development
workflow. AI tools supported the design exploration and implementation,
guided by my own professional background, requirements, creative
direction, and review.

------------------------------------------------------------------------

## About

I'm Adarsh Dileep, a software engineer with 7+ years of experience
across mobile and web development.

My primary focus is building and maintaining cross-platform mobile
applications with **React Native**. I also have experience with
**React.js** web applications and an earlier foundation in **PHP and
CodeIgniter** development.

I enjoy more than implementing features. I like investigating difficult
issues, tracing errors to their root causes, resolving dependency and
build problems, improving application reliability, and finding practical
engineering solutions.

### Areas of focus

-   React Native mobile application development
-   React.js web application development
-   PHP and CodeIgniter development experience
-   API and third-party SDK integration
-   Debugging, troubleshooting, and performance optimization
-   Application maintenance, upgrades, and release workflows

## Design and development with AI

This portfolio was created using an AI-assisted design and development
workflow.

AI tools supported the process of exploring the visual direction,
shaping page layouts, generating and refining implementation, and
iterating on the experience.

### Tools used

-   **Google Stitch** --- UI/UX design exploration and screen direction
-   **Google Antigravity** --- AI-assisted development and
    implementation

AI was used as a creative and engineering assistant, not as a substitute
for professional ownership. The portfolio's content, career details,
technical positioning, and final design decisions are directed and
reviewed by me.

I believe AI-assisted development works best when paired with clear
requirements, engineering judgement, careful validation, and an
understanding of the problem being solved.
